# arsenic

An audio instrument label. Spectral processors, terminal instruments, and sample tools.

Site source — Next.js, statically rendered. The catalog is registry-driven:
`components/registry-data.json` is the single source of truth and
`scripts/check-registry.mjs` enforces registry ↔ page parity at build time.
